30秒まとめ
当院のアプリは電子カルテを真ん中にして、予約・在庫・勤怠・画像などが自動でつながっています。
このページは「どこに入れたものが、どこに出てくるか」の一覧です。二度入力しなくていいところと、手で動かす必要があるところが分かります。
自動＝人が何もしなくてもつながる　ボタン＝人が押して渡す　これから＝まだつながっていない

2. 予約 ⇄ 電子カルテ

つながり何が起きるかいつ
自動予約 → 受付ボード今日の予約が朝、受付ボードの「予約」列に自動で並びます。手で入力する必要はありませんボードを開いたとき
自動再来機 → 受付ボード飼い主さまが再来機で受付すると、「予約」から「来院」へ自動で進みます。ここから受付からの経過時間が数え始めます受付した瞬間
自動予約 → 患者画面患者を開くと次回予約が上に出ます患者を開くたび
ボタン電子カルテ → 予約患者画面の［次回予約を取る］で、その子を選んだ状態で予約画面が開きます押したとき
まだ来ていない予約には経過時間が出ません。「来院」に進めた時刻から数えます。再来機を使わなかった方は、受付でボードの［来院］を押してください。

3. 電子カルテ ⇄ 在庫

つながり何が起きるかいつ
自動会計（処方） → 在庫お薬を処方して会計を保存すると、在庫が自動で減ります。在庫アプリで引く操作は要りません会計を保存した瞬間
自動在庫 → 電子カルテ処方するとき今の在庫数が見えます。発注点を割った薬も一覧できます常時
ボタン名寄せ処方名と在庫の品名が違う薬は減りません。一度ひも付ければ次から自動になります（📦在庫連携→🔗名寄せ）気づいたとき
注射・輸液など「処方として会計に載らない消費」は自動で減りません。これは在庫アプリ側で調整してください。

4. 勤怠のつながり

つながり何が起きるかいつ
自動勤怠 → 予約シフトと休みが予約の枠に反映されます（出勤していない日は枠が開かない）毎朝 7:15
自動勤怠 → 院内DB打刻データが院内のデータベースに写されます（勤怠ビューアで見られます）毎朝 7:20
自動勤怠 → 会計事務所月次の勤怠集計が自動で作られ、承認のうえ会計事務所へ送られます。ここが給与の元データです30分ごとに確認
これから電子カルテ ⇄ 勤怠今はつながっていません。「誰がどれだけ診たか」（人別の生産性）は、自作カルテの記録が貯まってから出します—
打刻を直したいときは勤怠側で申請します。予約の枠に反映されるのは翌朝です（当日すぐには変わりません）。

5. 診療の記録まわり

つながり何が起きるかいつ
ボタン電子カルテ → 音声カルテ患者画面の［🎙 録音］で、その子の録音画面が開きます（カルテNo.を入れ直さなくていい）押したとき
自動画像 → 電子カルテ撮影したレントゲン・エコーが、その子の時系列に自動で並びます撮影後まもなく
ボタン外注ラボ → 電子カルテ届いた結果ファイルを検査取込トレイで患者に割り当てると、検査値として入ります結果が届いたとき
ボタン電子カルテ → 各報告書患者画面から歯科・健診・フィラリアの報告書アプリを、その子で開けます押したとき
ボタン電子カルテ → 入院・症例バンク同じくその子で開きます押したとき

つながり何が起きるか

ボタン健診 → 公式LINE健診結果を公式LINEで送ります

7. まだつながっていないもの（正直な一覧）

これは今どうなっているか
電子カルテ ⇄ 勤怠つながっていません。人別の生産性は準備中です
電子カルテ → Ahmics（正カルテ）書き込みません（読むだけ）。Ahmicsへの転記は音声カルテ側が行います
レセプト（保険請求）作りません
注射・輸液の在庫消費自動で減りません（在庫側で調整）
